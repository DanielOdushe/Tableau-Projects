# Tableau Projects Portfolio

## Overview
This repository contains my collection of Tableau dashboards created across different domains including business, environmental data, HR analytics, finance, and more. The goal is to demonstrate data storytelling, dashboard layout skills, and analytical reasoning through interactive visualizations.

## Repository Structure
Each project folder contains:
- Tableau workbook file (.twb or .twbx)
- Dashboard preview image (PNG or JPG)
- Project summary and key insights (README inside project folder)
- Dataset source or reference
- Link to the published version on Tableau Public (if available)

## Skills Demonstrated
- Dashboard design and visual best practices
- Calculated fields and custom metrics
- Filters, parameters, and user-driven interactions
- Data cleaning and preparation inside Tableau
- Multi-sheet dashboard layouts
- Storytelling with data

## How To Use
1. Download the project folder you want to explore
2. Open the .twbx file in Tableau Desktop or Tableau Public
3. Review the insights document included in each project
